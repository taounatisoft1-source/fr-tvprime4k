Comment configurer IPTV Smarters Pro

IPTV Smarters Pro est l'application IPTV la plus utilisée au monde — gratuite, disponible sur quasiment tous les appareils, interface claire. Ce guide couvre la configuration complète : connexion, favoris, EPG, catégories, mode parental, dépannage. Valable pour Android TV, Fire TV Stick, iOS, Android mobile, Windows et Mac.

Publié le 2026-10-18 · Par l'équipe TVPrime4K

Étape par étape

01

Télécharger IPTV Smarters Pro pour votre appareil

L'app est disponible sur : Google Play Store (Android TV, Android mobile), App Store (iPhone, iPad, Apple TV), Amazon Appstore (Fire TV Stick, Fire TV Cube). Pour Windows ou Mac, téléchargez le fichier .exe/.dmg depuis le site officiel iptvsmarters.com.

02

Choisir la méthode de connexion : Xtream Codes vs M3U

Au premier lancement, l'app propose deux méthodes de connexion. Xtream Codes API (recommandé) : plus rapide, l'EPG se charge automatiquement, les catégories sont triées, les favoris sont stockés sur le serveur. M3U URL : fonctionne partout mais sans EPG riche, sans tri automatique.

03

Entrer vos identifiants Xtream Codes

Pour la méthode Xtream Codes, saisissez : Any Name (nom libre, ex: TVPrime4K), Username (reçu par e-mail), Password (reçu par e-mail), URL (le serveur, format http://xxx.yyy.com:zzz, reçu par e-mail). Appuyez sur Add User. La liste des chaînes se charge.

04

Organiser les favoris

Dans la liste des chaînes, appuyez long (ou clic droit) sur une chaîne → Add to Favorites. Vos favoris apparaissent dans la catégorie Favorites en haut. Pratique pour accéder rapidement à TF1, M6, Canal+, beIN Sports, etc. sans scroller 1000 chaînes.

05

Configurer l'EPG (guide électronique)

L'EPG s'active automatiquement avec Xtream Codes. Pour forcer le rafraîchissement : Paramètres → EPG Settings → Update EPG. Vous verrez le programme en cours et les 24 prochaines heures sur chaque chaîne. Appuyez sur une émission à venir pour la mettre en rappel.

06

Activer le contrôle parental

Paramètres → Parental Control. Définissez un code PIN à 4 chiffres. Vous pourrez ensuite verrouiller des catégories entières (ex: Adultes, certaines chaînes étrangères). Pratique dans les familles avec enfants.

07

Changer la qualité et le lecteur vidéo

Paramètres → Player Settings. Choisissez entre Built-in Player (par défaut, suffit pour 99% des cas), VLC Player (meilleur support des codecs rares), MX Player (fluidité maximale sur Android). Pour la qualité, laissez en Auto — l'app choisit la meilleure résolution selon votre bande passante.
